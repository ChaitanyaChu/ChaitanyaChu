I build AI systems that actually ship — multi-agent orchestration, real-time voice pipelines, and LLM-powered automation. Currently working as an AI Engineer building production ML/ETL systems and agentic workflows.

- Working on **Aria** — a 6-agent Claude orchestration system with A2A HTTP, custom MCP server, and human approval gates
